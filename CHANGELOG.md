# Changelog

Все изменения в проекте STNGrobot.

## [1.0.0] - 2025-03-18

### Добавлено

- ✅ Регистрация пользователей через /start
- ✅ Создание заявок текстовым сообщением
- ✅ Автоматическое уведомление админов о новых заявках
- ✅ Управление ролями (root, admin, spec, user)
- ✅ Управление группами специалистов
- ✅ Назначение специалистов на заявки
- ✅ Отправка заявок всей группе специалистов
- ✅ Выполнение заявок с уведомлением всех сторон
- ✅ История заявок для пользователей
- ✅ Команды для админов (/admin, /requests, /add_group, и др.)
- ✅ Команды для root (/add_admin, /remove_admin, /users)
- ✅ Middleware для работы с сессией БД
- ✅ Репозитории для работы с данными
- ✅ Логирование действий
- ✅ Миграции базы данных (Alembic)

### Техническая информация

- Стек: Python 3.10+, aiogram 3.x, SQLAlchemy 2.x, PostgreSQL
- Асинхронная работа с БД через asyncpg
- Inline-клавиатуры для взаимодействия
- Разграничение прав доступа через фильтры
