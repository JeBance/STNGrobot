# STNGrobot - Telegram-бот диспетчер заявок

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![aiogram 3.x](https://img.shields.io/badge/aiogram-3.x-green.svg)](https://docs.aiogram.dev/)
[![SQLAlchemy 2.x](https://img.shields.io/badge/sqlalchemy-2.x-yellow.svg)](https://www.sqlalchemy.org/)

Бот для автоматизации диспетчерской службы. Позволяет пользователям отправлять заявки, админам распределять их по специалистам, а специалистам отмечать выполнение.

## Возможности

- ✅ Создание заявок в один клик (просто отправьте текст)
- ✅ Автоматическое уведомление админов о новых заявках
- ✅ Распределение заявок по группам специалистов
- ✅ Назначение конкретного специалиста или отправка всей группе
- ✅ Уведомления о выполнении заявок
- ✅ Иерархия ролей с разграничением прав
- ✅ История всех заявок
- ✅ Асинхронная работа с БД PostgreSQL

## Роли

| Роль | Описание | Права |
|------|----------|-------|
| **root** | Супер-админ | Полный доступ, назначает админов |
| **admin** | Администратор | Управление заявками, группами, специалистами |
| **spec** | Специалист | Получает и выполняет заявки |
| **user** | Пользователь | Создаёт заявки |

## Установка

### 1. Требования

- Python 3.10+
- PostgreSQL 12+
- Telegram Bot Token (от [@BotFather](https://t.me/BotFather))

### 2. Клонирование и установка

```bash
cd /root/git/STNGrobot

# Установка зависимостей
pip install -r requirements.txt

# Или используйте скрипт установки
chmod +x install.sh
./install.sh
```

### 3. Настройка

```bash
# Скопируйте файл настроек
cp .env.example .env

# Отредактируйте .env
nano .env
```

**Обязательные параметры:**

| Параметр | Описание |
|----------|----------|
| `BOT_TOKEN` | Токен бота от @BotFather |
| `ROOT_ID` | Ваш Telegram user ID (супер-админ) |
| `DATABASE_URL` | Строка подключения к PostgreSQL |

**Пример DATABASE_URL:**
```
postgresql+asyncpg://user:password@localhost:5432/stngrobot_db
```

### 4. База данных

```bash
# Создайте базу данных
createdb stngrobot_db

# Примените миграции
alembic upgrade head

# Или через скрипт
python3 run_migrations.py upgrade
```

## Запуск

```bash
# Через скрипт
./run.sh

# Или напрямую
python3 -m bot.main
```

## Команды

### Для всех пользователей

| Команда | Описание |
|---------|----------|
| `/start` | Регистрация и главное меню |
| `/my_requests` | История своих заявок |
| `/help` | Справка по командам |

### Для админов и root

| Команда | Описание |
|---------|----------|
| `/admin` | Панель администратора |
| `/requests [status]` | Список заявок (new/assigned/completed/cancelled) |
| `/add_group <название>` | Создать группу специалистов |
| `/delete_group <название>` | Удалить группу |
| `/list_groups` | Список групп |
| `/add_spec <ID> <группа>` | Добавить специалиста в группу |
| `/remove_spec <ID>` | Удалить специалиста |
| `/list_specs` | Список специалистов |

### Только для root

| Команда | Описание |
|---------|----------|
| `/add_admin <ID>` | Назначить админа |
| `/remove_admin <ID>` | Снять админа |
| `/list_admins` | Список админов |
| `/users` | Все пользователи системы |

## Сценарии использования

### Сценарий 1: Создание заявки пользователем

1. Пользователь отправляет текст: `"Вагон Л-12. Не работает свет"`
2. Бот создаёт заявку и отвечает: `"✅ Заявка №1 принята"`
3. Все админы получают уведомление с кнопками групп

### Сценарий 2: Назначение специалиста

1. Админ нажимает на группу (например, "Электрики")
2. Появляются кнопки со специалистами группы
3. Админ выбирает специалиста или "Отправить всем"
4. Специалист получает заявку с кнопкой "Выполнено"

### Сценарий 3: Выполнение заявки

1. Специалист нажимает "Выполнено"
2. Заявка помечается выполненной
3. Админ и пользователь получают уведомления

## 🔧 Техническая информация

### Стек технологий

- **Язык:** Python 3.10+
- **Telegram API:** aiogram 3.x (асинхронный)
- **База данных:** PostgreSQL
- **ORM:** SQLAlchemy 2.x (async)
- **Миграции:** Alembic

### Модели данных

- **users** - пользователи (telegram_id, username, role)
- **groups** - группы специалистов (name, created_by)
- **specialists** - специалисты (user_id, group_id)
- **requests** - заявки (user_id, text, status, assigned_to)
- **request_assignments** - назначения (request_id, specialist_id, status)
